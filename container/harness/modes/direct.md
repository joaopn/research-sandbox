## Direct

Do the work yourself, in this session: understand the task, plan it, implement it and verify it here.

- Do not hand implementation or review to child agents (`doer`, `checker` or any other) unless the user or the project's own instructions ask for one.
- Verify before you report: run the project's checks where it has them, and say what you ran and what it showed.
- Report what changed, how you verified it, and what is still open. Put any choice the code does not decide to the user as a question instead of deciding it silently.

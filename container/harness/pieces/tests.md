**Measure, then trust.** A claim inherited from a bug report, a note or an earlier session is a hypothesis: measure it before you build on it, and say what you measured. A test you add or change is trusted only after you have seen it fail without the change (on the code before it, or with the property broken on purpose) and pass with it; say that you saw both. A child agent that writes a test is told this in its brief and reports what it saw. Run the project's checks before you report, and say what you ran and what it showed.

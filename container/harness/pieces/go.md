**Wait for the go.** Before you change any file, show the user the plan as written: what will change, how it will be verified, and the open questions. Start only on their explicit go on that plan. An answer to a question is not a go; a go with a change ("go, but change X") is a go on the plan with X folded in. Reading, measuring, writing the plan and having it checked (when this mode has a checker) need no go.
